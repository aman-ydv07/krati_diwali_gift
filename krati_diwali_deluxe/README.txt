KRATI'S DIWALI WEBSITE — QUICK GUIDE

FILES
- index.html: page structure, all captions and text, image filenames
- style.css: colours, layout, collage and animations
- script.js: scroll reveals, progress bar, sparkles, photo tilt and hidden message
- assets/: place your images here

ADD PHOTOS
Use these exact filenames (JPG):
krati-main.jpg
photo-01.jpg through photo-12.jpg
krati-candid.jpg

If you use another extension or filename, edit the corresponding src="..." in index.html.
Missing photos show a placeholder.

CUSTOMIZE TEXT
Open index.html and edit the headings, paragraphs and figcaption text.
Each collage photo has its own caption.

ANIMATIONS
- Photos/text slide or drop into view as you scroll
- Staggered entrance timing
- Top scroll progress bar
- Floating gold sparkles + sparkle button
- Photo card hover lift and gentle mouse tilt on desktop
- Final hidden message button

PREVIEW
Keep all files and the assets folder together. Double-click index.html to preview in a browser.

PUBLISH
Upload the complete folder to GitHub Pages or Netlify to get a shareable public link.
Do not upload only index.html; CSS, JS and assets are required.
